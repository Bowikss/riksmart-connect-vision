# RIK Platform Launch

Build a single-page landing page (not a multi-page site, one scrollable page with smooth-scroll anchor navigation) for RIK (full legal name "RIK Serviss") — a smart infrastructure / IoT technology company building autonomous, solar-powered, connected safety hardware for cities and road authorities. Position RIK as a technology company with a platform (sensors + solar power + LoRa connectivity + centralized monitoring), not as a single-product business. Its first flagship product is a smart pedestrian crossing safety system, featured prominently but framed as "our first deployed solution," not the whole identity of the company.

Brand identity:

Logo: a shield-shaped badge in deep navy (#0F2A44) with a bold letter "R" inside in off-white (#F3F8FB), and a small cyan accent dot (#1BB4E8) near the top-right of the shield. I'll upload the actual logo file — use it in the sticky top bar and footer.

Color palette: primary deep navy #0F2A44 / #112A45, accent cyan #0E7FBF / #1BB4E8, light background #FFFFFF with a very subtle tech grid + faint connected-dot pattern (circuit/network texture) in the far background, body text in slate #27435E, muted captions in #5B7488. Status colors used sparingly: green #15A85F, amber #D98008, red #D93A3A.

Typography: bold modern sans-serif for headings, heavy weight, tight letter-spacing on small uppercase labels; clean readable sans for body text. Generous white space, rounded cards with soft shadows, smooth fade/slide-in scroll animations, subtle hover glows.

Overall feel: clean, professional "smart infrastructure / IoT platform" company — like a hardware-tech startup, not a single-product brochure.
